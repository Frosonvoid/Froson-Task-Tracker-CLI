A CLI-based task tracker system built with Python and SQLite featuring CRUD operations, task status management, and persistent local database storage.

Features:
Add tasks
View all tasks
Update existing tasks
Delete tasks
Task status management
Input validation
Persistent SQLite database storage
Menu-driven CLI interface

Technologies Used:
Python
SQLite3

Project Structure:
Tasktracker.py   -> Backend logic and database operations
main.py          -> Application flow and CLI menu system
task.db          -> SQLite database file Created by tasktracker.py

CRUD Operations
Operation	Description
Create	Add new tasks
Read	Display all tasks
Update	Modify existing tasks
Delete	Remove tasks

Task Status Options
To Do
In Progress
Done
Dropped


Learning Goals

This project was built to practice:

Python fundamentals:
SQLite database integration
CRUD operations
Modular programming
Input validation

Backend logic structuring

How to Use the System
Run the program using:
python main.py
Select an option from the menu:
1. Show Tasks
2. Insert Task
3. Delete Task
4. Update Task
5. Close Program
Follow the prompts to:
add new tasks
update task details
delete tasks
manage task statuses
All tasks are automatically saved in the local SQLite database (task.db).
